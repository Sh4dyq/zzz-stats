Проверено всё, что игрок видит в `demo.html`: лобби, панели, окна, журнал, события, глобальные события, предметы, эффекты регионов, модификаторы, режимы боёв и онлайн-лобби.
Лор-термины сверены с официальной русской локализацией ZZZ: патчноуты HoYoverse на русском из API сайта zenless.hoyoverse.com/ru-ru. Номера новостей указаны в таблице.
Механика, числа, id, ключи объектов, CSS-классы и id элементов не менялись. Тесты после правок проходят: `node --check`, `smoke2` (демо и полная версия), `mp-test`, `bot-run`.

## 2. Заметные правки по файлам

**demo.html**
- Вступление в лобби короче и точнее по лору. Вайфэй — полуостров, Розкелифер — остров, это не районы Нью-Эриду. Теперь: «через Нью-Эриду и его окрестности».
- «карты регионов» → «эффекты регионов»: в демо нет карт событий регионов.
- «места вводятся…» → «результат — в пару нажатий»: игрок вводит результат, места игра считает сама.
- «Продолжить сохранённую» → «Продолжить партию».
- Строка ожидания: «Ждём: бой, событие или решение ведущего».

**js/ui/app.js**
- Род числительного: «меньшее/большее из двух» → «меньший/больший из двух» (речь о броске).
- Один термин на одно понятие:
  - «негативное воздействие» → «негативный эффект»;
  - «Блок агента» → «Запрет агента» (как в описании предмета);
  - «Аномалия: …» → «Аномальный эффект: …».
- «Горячая картошка: взрыв через N х.» → «ходов до взрыва — N».
- Регион без эффекта: «спит» → «не активен». Раньше было похоже на эффект «Остров спит».
- Окно Охоты переписано короче, вместо «наступил» — «охотник». На автоохоте «наступившим» считался игрок, который на клетку не вставал.
- Общий бой и дуэли: «посчитаются сами» → «игра посчитает сама».
- Памятка:
  - «Шулер» → «Шулерский кубик»;
  - «GC» → «Grand Challenge»;
  - «+1 отстающему» → «игроку на последнем месте +1»;
  - для возврата на Start указано «+1 очко и предмет» — так работает движок;
  - для боёв с клеток сказано, что дуэли играются после общего боя, а места игра считает сама;
  - «Тайник запечатан» → «Тайник закрыт».
- Мелочи: «Дать» → «Выдать», текст окна «Ведущий», текст подтверждения новой партии.

**js/engine/game.js** (журнал, заголовки выборов)
- Ошибка согласования «получает аномальный Ловушка / Ролики». Теперь название предмета в кавычках, а пометка отдельно: «получает предмет «Ловушка» ✦ аномальный». Так же в строках «использует», «теряет», «крадёт», «продаёт» и «сгорает».
- Строки журнала без указания рода: «X: Оглушение, бросок пропущен», «X: назад на N кл. → …», «X: вызов на дуэль».
- Кнопка броска стала глаголом: «Бросок d6» → «Бросить d6». Похожие правки: «Без предмета → бросок» → «Бросить без предмета», «Пройти» → «Пропустить» (Гача).
- Выбор клетки: «Куда идёшь на N? Выбери клетку» → «Ход на N кл.: выбери клетку».
- Ломбард:
  - к цене добавлено «очк.»;
  - кнопка показывает итоговую цену с учётом «Распродажи в Нью-Эриду» (×2). Раньше на кнопке была одна цена, а начислялась другая.
- Новый этап:
  - «Телепорт на Start (+1)» → «На Start (+1 очко и предмет)»;
  - «Остаться на Ш05» → «Остаться: Сундук · Шестая улица» — внутренний код клетки больше не показывается.
- Разное:
  - «Ты первым прошёл X» → «Ты первым в регионе X»;
  - «отстающий» → «последнее место»;
  - «оч.» → «очк.» (одно сокращение везде);
  - «Телепорт сработал с ловушкой» → «Сбой телепорта»;
  - «Заведение переехало» → «Открылось другое заведение»;

  - «Золотой Bangboo пуст!» → «Тайник оказался пуст!»;
  - «Зеркало отражает … в X» → «… на X».
- Лор: «Тур де Инферно», «Inter-Knot», «Холлоу», «Мяумяу» заменены (см. таблицу).

## 5. Не проверено или требует решения

- **Knot TV** (D-07, G-23): официальное русское название не нашёл, оставлено как есть.
- **Мяучело**: подтверждено только сторонним гайдом.
- **Патрули Общественной безопасности** (E-Ш2): официальное название ведомства не подтверждено, оставлено.
- Оставлены как есть, источники не найдены:
  - Пошлина Мотор-лиги (E-Б5);
  - Глушилка ESD (E-Р4);
  - Колесо Нотфлайта;
  - Диффчики — возможно, имелись в виду денни, официальная валюта (Dennies);
  - тирен (модификатор «Фурри вторник»).
- **«Grand Challenge»** и **«Джокер»** — термины самой игры, не ZZZ. Grand Challenge оставлен по-английски, как в лобби полной версии.
- **«Оборона шиюй 5»**: сейчас в ZZZ пятый уровень обороны называется «критическим узлом» (в патчноутах — «критического узла»). Подпись можно сменить на «Оборона шиюй: критический узел», если она поместится в интерфейсе.
- **Возможная ошибка механики (не исправлял)**: `game.metric()` не находит режимы GC с суффиксом ` ×3`. Поэтому `'Annihilation ×3'` считается по счёту, а должен по таймеру, и в окне боя показывается подсказка «счёт — больше лучше». Варианты исправления:
  - добавить ключи `×3` в `NP.MODE_METRIC`;
  - или в `metric()` отрезать суффикс: `NP.MODE_METRIC[mode.replace(/ ×\d+$/, '')]`.
