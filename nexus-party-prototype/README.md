# Nexus Party — прототип

Игра за одним экраном (hot-seat) на 2–8 игроков. Нужна, чтобы проверить, как играется полный цикл: карта, ходы, гонка за отметками регионов, предметы, события, этапы и экономика очков. Бои ZZZ игроки играют в самой игре, а в прототип каждый вводит свой результат: в Shiyu 1–4 и Annihilation таймер (м:сс, меньше лучше), в Shiyu 5 и Deadly Assault счёт (больше лучше), плюс бонус за модификаторы. Места, победители дуэлей и обход лидера на Охоте считаются сами; режим Охоты выбирает лидер.

## Запуск
Открыть `index.html` двойным кликом. Сервер, сборка и интернет не нужны.

- **Ведущий** (кнопка вверху) — ручные правки: очки, статусы, предметы, позиция фишки, бросок любого кубика.
- Партия сохраняется в браузере в начале каждого хода. Кнопка «Продолжить сохранённую» в лобби её восстанавливает.
- «Сохранить файл» и «Загрузить файл» — экспорт и импорт партии в JSON, например чтобы приложить к баг-репорту.
- В окнах боёв есть кнопка «Случайно» для быстрых тестовых прогонов.

### Интерфейс io (задел под онлайн)
Движок ничего не знает о странице. Каждое решение он запрашивает через объект `io`, и каждый метод возвращает Promise:
- `choose({player, title, options, kind})` — выбор варианта, клетки (`kind: 'cell'`) или игрока;
- `wait({player, kind: 'roll'})` — кнопка броска;
- `fight({kind: 'fight' | 'duels' | 'hunt', ...})` — ввод результатов боя;
- `eventCard({player, card})` — карточка события;
- `update`, `log`, `save`, `gameOver`.

Сейчас `io` реализует страница (`js/ui/app.js`), в тестах — бот (`tools/bot-run.js`). Для онлайн-версии на nexus-shiyu.com тот же движок можно запустить на сервере, а `io` отправит запросы нужному игроку через сокет. Состояние партии целиком лежит в одном JSON-объекте вместе с сидом случайности, поэтому его можно хранить в Supabase.

## Что автоматизировано
- Карта, направления, развилки, отметки регионов, круги, проход Start (предмет, конец этапа при 4/4), активные и пассивные клетки при перемещении не своим ходом.
- Все 15 типов клеток с аномалиями; Гибриды перегенерируются каждый этап.
- Бои: общий бой раунда, Дуэль на клетке с парами, Перчатка, Охота и автоохота, бой перехода, Grand Challenge (3 боя). Режим и модификаторы выбираются случайно по весам из таблицы.
- Этапы: бонус за скорость, переход с выбором «Start или остаться», порядок хода по очкам, досрочная победа по порогу.
- 25 предметов и их аномальные версии, статусы.
- 23 эффекта регионов и их активация с выбором 1 из 2. Шестая улица активна с начала этапа.
- События: R или L по доле, аномалия даёт 2 карточки, не своим ходом выпадает только R, колода без повторов (по желанию), условия «только лидеру / последнему / есть предметы», проверка условий доп. вариантов.

## Что делается вручную
- **Исходы событий.** Карточка показывает варианты. Под выбранным вариантом появляются быстрые кнопки, собранные из текста: броски нужного кубика, ±очки, предметы, статусы, сдвиги, Контракт. Сложные механики, помеченные ревью (тайные ставки, жетоны, отложенные выплаты), разыгрываются этими кнопками и через «Ведущего».
- **Контракты, Утконос, выполнение модификаторов Колеса Нотфлайта, Блок агента.** Прототип только показывает их, проверка остаётся за игроками.
- Ставки на дуэли, ростер, драфт, отдых отрядов.

## Правила, уточнённые по плейтесту
1. Бои с клеток по умолчанию играются в конце раунда одним общим боем, модификаторы суммируются. Настройка «Бой с клетки: сразу» включает немедленный бой. Бои из очереди не сгорают: если этап закончился посреди раунда, они играются перед бонусами этапа.
2. Телепорт на Start в начале этапа считается проходом: +1 очко и предмет.
3. Щит и Зеркало нужно применить, тогда появляется статус. Зеркало отражает эффект в источник, а если источника нет — в случайного соперника.
4. Зона Жнеца — клетка и её соседи внутри того же региона. Гибриды не создают Жнеца ближе 2 клеток к другому Жнецу.
5. Охота: обошедший наступивший +3, остальные обошедшие +2, лидер +1 за каждого необойдённого. Аномальная Охота даёт +1 модификатор, а победивший наступивший меняется с лидером позициями на карте.
6. Перчатка: только бонус +2/−1, против лидера +3/−2, без очков за место.
7. Гача: одна попытка за визит, стоит 2 очка. Гарант срабатывает на следующем визите и держится до конца этапа. Казино: одна ставка за визит.
8. Тайник закрывается до конца этапа после первого получившего награду.
9. Грузовик Блейзвуда: Б01 → Б02 → Б03 → Б04 → Б05 → Б12 → Б11 → Б06 → Б01.
10. Отбрасывание назад идёт случайно по входящим связям, по двусторонней связи тоже.
11. Телепорт (клетка, Разлом) не может ни встать на Start, ни пройти через него. Радиус телепорта — 1,5× броска (было 2×). Отбрасывание назад тоже не проходит через Start.
12. Ловушка телепорта (17%) — любое случайное событие, избежать нельзя.
13. Бросок кубика сразу подсвечивает все клетки, куда можно дойти. Игрок выбирает конечную клетку, промежуточных развилок нет.
14. Глобальные события включены: одно в начале игры и каждого этапа, действует весь этап. Из мгновенных оставлены сильные: G-03 и G-12 работают, G-18 и G-21 пока не реализованы. Слабые мгновенные (G-08, G-09, G-11, G-15, G-16, G-20) убраны. Также не реализованы G-01, G-17, G-19, G-24.
15. Карта: двусторонняя связь только Б02–Б06. Б06→Б07, В03→В12, Р09→Р08 стали односторонними.
16. Клетки «Очки» и «Опасность» дают ±2 (аномальные ±4).
20. Сундук всегда даёт случайный предмет, без выбора. E-Ш4: предмет не ниже редкого; E-В5: предмет и +1 очко.
21. Все начинают игру с 1 очком (настройка startPoints).
17. Аномальная Коробка: владелец выбирает цель; себе выпадает только хорошее, сопернику только плохое (Щит и Зеркало срабатывают). Обычная Коробка под «Плохим днём» даёт только плохое.
18. Аномальное Колесо Нотфлайта: всем +1 модификатор на следующий бой; +1 владельцу за каждого выполнившего вносится вручную в бонусах боя.
19. Аномальная Перчатка: бросивший выбирает режим дуэли, он показывается в заголовке боя.

## Демо
`demo.html` — отдельная демонстрационная сборка: без переключения на полную версию, без импорта и экспорта файлов, со своим сохранением. В демо:
- короткая партия на 2 этапа;
- 14 своих коротких событий (`NP.DEMO_EVENTS` в `js/engine/events.js`): игрок выбирает вариант, а исход (очки, предметы, статусы, броски, сдвиги) считается сам и показывается итогом. Негативное проходит через Щит и Зеркало;
- без предметов с ручной проверкой (Колесо Нотфлайта, Утконос);
- игрокам не показываются коды клеток: в выборе и журнале пишется тип клетки и регион;
- 7 глобальных событий, которые не требуют ручного разбора;
- в лобби только число игроков, имена и этапы.

## Онлайн (демо)
В лобби `demo.html` есть блок «Онлайн». Хост вводит имя и нажимает «Создать комнату», остальные вводят код из 5 символов (или открывают ссылку из лобби хоста) и нажимают «Войти». Хост может добавить игроков, которые сидят за его экраном, и затем начинает партию.
- Галочка «Только вести партию» убирает хоста из игроков: он ведёт партию, решает глобальные события и записывает бои, но не ходит. Нужно минимум 2 игрока-гостя (или игрока на его экране).
- Партию ведёт браузер хоста (`js/net/mp.js`), гости получают состояние и отвечают на свои решения: выбор клетки, бросок, итоги событий, результат боя.
- В бою каждый вводит свой таймер или счёт. Хост видит, кто уже прислал результат, и может нажать «Заполнить за всех», чтобы проставить пустые результаты (симуляция) и записать бой.
- Связь — Supabase Realtime (тот же проект, что у nexus-shiyu.com, канал broadcast без таблиц). Нужен интернет; файл можно открыть и локально.
- Без сети: добавить `#local` к адресу, тогда комната работает между вкладками одного браузера.
- Гость, перезагрузивший вкладку, входит заново по тому же коду и продолжает. Хост после перезагрузки нажимает «Продолжить свою онлайн-партию».

## Пересборка событий из таблицы
1. Выгрузить лист «События» в JSON (ответ Sheets API `values.get`).
2. `python tools/sheet-to-events.py part1.json part2.json`.
